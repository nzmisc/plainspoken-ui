# Concepts

Ideas for austere-ui that are worth writing down but are **not promises**. A concept may be built,
changed beyond recognition, or dropped. Nothing here is a roadmap.

Each concept has a status:

| Status | Meaning |
|---|---|
| **wanted** | Decided: we want it. Not built yet, and no date |
| **open** | Being considered; no decision yet |
| **later** | Liked, but not for the first release |
| **set aside** | Considered and not wanted for now; kept so the reasoning isn't lost |

When a concept is built, its section links to the work and moves to the bottom under "built".
